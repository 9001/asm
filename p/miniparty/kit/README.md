## copyparty stuff
* `copyparty-sfx.py` runs *almost* anywere
* `copyparty-help.html` all of the config options
* `../sm/copyparty.conf` an appropriate config file
* `u2c.py` commandline file-uploader
  * can be dowloaded from copyparty at runtime; see `/?hc`

## other stuff
* `r0c.py` the telnet chatserver, runs anywhere
  * `r0c-client.sh` non-telnet client for linux/macos
  * `r0c-client.ps1` non-telnet client for windows
