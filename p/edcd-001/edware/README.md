## copyparty stuff
* `copyparty-sfx.py` runs *almost* anywere
* `copyparty.pyz` primitive alternative if sfx doesn't work
* `copyparty.exe` (win8 or later), has thumbnail support
* `copyparty32.exe` (win7 or later), only basic features
* `u2c.exe` (win7 or later) commandline file uploader
  * the crossplatform `u2c.py` is served by copyparty at runtime; see `/?hc`

## other stuff
* `r0c.py` the telnet chatserver, runs anywhere
* `smf.py` file deduplicator
* `python-3.11.9.zip` just in case you need it
* `src/` source code of stuff i made (git-bundles)
* `src/asm.gb` the source code of this cd
